# Fstack role roster

The main mode remains the coordinator. Roles are instructions passed to actual host agents, not proof of a running service. Model assignments are private configuration; the public package contains no API keys or entitlements.

| Role configuration | Job and prompt |
| --- | --- |
| research implementation | Ordinary bounded artifact work, [fstack agent](fstack-agent.md) |
| judgment and prose | Synthesis and final explanation under the relevant workflow |
| hardest tasks | Difficult cross-cutting design using the architect/arena workflow |
| how explorer | [How explorer](../skills/fstack-how/references/explorer-prompt.md) |
| how explainer | [How explainer](../skills/fstack-how/references/explainer-prompt.md) |
| why investigators | [Source investigator](../skills/fstack-why/references/investigator-prompt.md) |
| why synthesizer | [Evidence synthesizer](../skills/fstack-why/references/synthesizer-prompt.md) |
| arena runners / architect runners | Independent designs, [design runner](../skills/fstack-architect/references/runner-prompt.md) |
| arena cross-judge pool | One eligible different-family judge, [cross judge](cross-judge.md) |
| swarm workers | Coverage or race brief from [swarm](../skills/fstack-swarm/SKILL.md) |
| interrogate reviewers | [Adversary](adversary.md), technical and economic channels |
| verifier | [Independent verifier](verifier.md) |
| reflect tooling / judgment / divergent / synthesizer | Matching [reflect references](../skills/fstack-reflect/SKILL.md) |

Each spawn records actual model, role, goal, input identity, source cutoff, expected output, writable location and result. Missing family diversity is a recorded gap. Configure using [setup](../skills/fstack-setup/SKILL.md).
