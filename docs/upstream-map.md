## Deliberate semantic changes

- Finance has separate artifact integrity, thesis support and performance evidence outcomes.
- Economic uncertainty remains visible alongside rerun-proven technical defects.
- Strategy search uses development data; evaluation reuse changes its evidence status.
- Research release does not authorize trading, private-data publication or external communications.
- Codex role/model/tool detection replaces Cursor-specific names and paths. Missing family diversity is a gap.
- Journal and verification helpers use cross-platform Python. Optional original developer runtimes are not bundled.
- Generated raw TLA+/TLC logs and binary art are outside the finance package; developer guidance links to the pinned source.
- Existing upstream contradictions are not inherited as permission. In particular, forensics cannot mutate brokerage state and automation is not implicitly enabled.

The 24 principle mappings are included both in the skill table and the machine-readable principles array. The 23 original playbooks each have an explicit disposition.
