# Evidence and report journey

## Sub-features

Original-source lookup, duplicate-source detection, contradictory figures, missing consensus and faithful final report labels.

## How to get to it (user POV)

Use the user's actual question and authorized source packet, with the same information cutoff for all reviewers.

## Driving it with the harness

Record source locations and dates, compare the report's claims against them, and verify the linked receipt's current artifact identities. Inspect actual source/tool activity rather than a candidate claiming it searched.

## Gotchas

Search snippets are leads. Syndicated copies are one origin. A mathematically correct output can coexist with an economically unsupported thesis. Unknown consensus remains unknown, and a stale receipt must not remain verified.
