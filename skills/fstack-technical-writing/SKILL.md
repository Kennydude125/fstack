# Technical financial writing

Identify the reader and task before writing. A research memo supports a decision, a methodology reference defines reproducible terms, and an operating guide gives executable steps. Keep these purposes clear.

For a memo lead with the supported conclusion and largest unknown, then evidence, competing explanation, expectations gap, valuation/risk where relevant, falsification conditions and next observation. Separate fact, source statement, inference, assumption and forecast. Cite actual original sources near material claims, preserving dates, currency, units and financial periods.

For a methodology reference define formulas, inputs, conventions, information cutoff, model limitations and reproducibility command. For an operating guide include prerequisites, actual commands, observable success/failure, evidence locations and safe cleanup. Do not substitute a confident summary for a rerunnable calculation.

Use unslop for clear language. Remove padding and unsupported attribution while retaining substantive assumptions and uncertainty. A private research journal or real portfolio data is not public documentation; sanitize or use synthetic examples before publication.
