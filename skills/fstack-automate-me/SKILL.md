# Automate me

Turn recurring, evidenced research conventions into a personal skill. This orchestrates authorized-history mining, the host skill creator and unslop.

1. Inspect the user's named existing personal skill and ask only if update versus replacement is unclear. Preserve established preferences not contradicted by new evidence.
2. Mine only the authorized workspace records, using parallel slices for a large corpus. Require recurring evidence across slices before codifying a pattern. A one-off winning trade is not a process rule.
3. Ask a small number of material preference questions that history cannot settle. Do not infer risk capacity, investment horizon or trading authority from habits.
4. Cluster supported preferences into relevant sections: response style, evidence, research depth, collaboration, verification and record keeping. Skip generic or unsupported sections.
5. Use the host skill creator to draft or update the private project skill. Reference existing skills by path instead of duplicating their content. Follow the host's invocation defaults and user choices.
6. Show concrete changes, iterate on feedback, validate metadata/references and apply within authorized scope. Do not edit installed plugin caches or publish private history.

Deliver the resulting destination, supported rules, changes actually applied and unresolved preferences. A recurring research workflow can be captured without creating an automatic schedule.
