# Swarm

Open Frame, Fan out, Aggregate and Report as the phase list.

## A. Frame

State the completion predicate and artifact. Choose partitioned coverage, a race, or mixed shape. Before a race declare first-pass, rank-all or best-of and its selection criteria. Use configured `swarm workers` unless a comparison deliberately assigns models per arm. Give each worker its own output location.

Every brief includes the original goal, exact slice, information cutoff, input hashes or immutable source identity, verification method and required report. For a measurement specify sample definition, count and order. A report is PASS, ISSUES or BLOCKED with evidence. PASS describes the assigned work, never future investment returns.

## B. Fan out

Spawn independent workers concurrently within real host limits. Each reads its relevant role prompt and principles. Do not share writable results. Workers return every demonstrated issue in scope and any unavailable source or model. On dropout continue where possible, preserving the uncovered slice.

## C. Aggregate

Read terminal results and inspect their evidence. Reject a report missing required input identity or measurement method, and retry that slice once with the complete brief. After a second failure record a gap. Every required slice needs an evidence-bearing result. Apply the declared race rule; a coverage gap never becomes a pass.

## D. Report

Return one consolidated result with slice status, concise issues, evidence pointers, gaps and dropouts, plus the race rule if used. Keep raw reports as artifacts. The coordinator owns the conclusion and any canonical journal update.
