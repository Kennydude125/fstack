# Teach

Run how for financial mechanics and why for evidence-backed reasons, using the same instrument identity and information cutoff. Weave the results into one explanation for the user's knowledge level. Build concepts before equations, show a small labeled example when useful, and connect each assumption to its effect. Preserve the original confidence tiers and source gaps. Explain scenarios as scenarios and never teach an unverified narrative as a known cause.
