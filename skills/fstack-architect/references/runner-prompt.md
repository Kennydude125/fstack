# Design runner

Produce one coherent design for the same task and fixed grounding packet the other independent runs receive. Start with the user's intended question/caller usage. Define inputs, outputs, units, cutoff, assumptions, transformation boundaries, ownership and observable verification. Compare genuinely different structural alternatives in your own rationale and select one. Keep strategy evaluation data hidden from development choices. Do not inspect other candidates or their rubric. Write only the assigned output artifact and rationale.
