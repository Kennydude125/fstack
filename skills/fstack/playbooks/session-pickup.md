# Session pickup

1. Read the supplied run capsule, original user goal, journal, checkpoint, manifest and evidence receipts. Prior history is authoritative for recorded intent and completed work, not for stale market facts.
2. Verify current input and artifact identities before trusting inherited completion claims. Reuse valid completed work and identify only what must be refreshed or rechecked.
3. Restore the selected playbook and exact remaining steps. Preserve original forecasts, quote times, assumptions and failed attempts. Append a new start event for the new run.
4. Continue from the next justified action. If material records are unavailable, name the gap rather than inventing history or rerunning a backtest and calling it the original prediction.

See the [main mode](../SKILL.md) for linked peer skills and the [finance contract](../../../references/finance-contract.md) for shared artifact and authority rules.
