# Autopilot full

1. Pin an explicitly authorized queue of independent research tasks with per-item finish conditions and shared constraints. Do not add queue members silently.
2. Give each item one owner through research, correction and independent verification. Keep worker outputs and user data isolated. Use fresh agents for new items.
3. Process ready items within host limits and inspect actual artifacts. Revalidate changed inputs, retry once where appropriate and keep failures visible.
4. Finalize each item only after its required verification. Automatic research completion never implies publishing private content or submitting financial orders.
5. Return queue outcomes, evidence, blockers and remaining work. Preserve an audit trail and stop propagation.

See the [main mode](../SKILL.md) for linked peer skills and the [finance contract](../../../references/finance-contract.md) for shared artifact and authority rules.
