# Autonomous run

1. Define one bounded research task, its evidence-based completion predicate, scope, attempt budget and audit location. Use figure-it-out if no narrower workflow fits.
2. Execute the selected workflow, independently checking each unit. Keep decisions and rejected attempts in the canonical journal.
3. Continue authorized reversible work without routine permission questions. Stop for user stop, material missing authority, exhausted attempts or a genuine external blocker. Never silently relax the predicate.
4. Propagate stop to child work and preserve a checkpoint at an atomic boundary. Finalize through Shipping if required gates pass; otherwise report a precise gap or inconclusive result.

See the [main mode](../SKILL.md) for linked peer skills and the [finance contract](../../../references/finance-contract.md) for shared artifact and authority rules.
