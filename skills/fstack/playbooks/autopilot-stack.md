# Autopilot stack

1. Apply Autopilot full's ownership, isolation, bounded retries and independent verification to a dependency-ordered research queue.
2. Stack an artifact only on a dependency it actually uses. Keep unrelated work independent.
3. Build and verify the contiguous ready run, stopping at the first unmet gate. Keep final financial decisions for the user; deliver the verified package and remaining gap.

See the [main mode](../SKILL.md) for linked peer skills and the [finance contract](../../../references/finance-contract.md) for shared artifact and authority rules.
